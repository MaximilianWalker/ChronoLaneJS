# ChronoLaneJS

ChronoLaneJS is a modern, timezone-aware calendar for React. This Storybook is
the executable catalog for its public API: every example renders a real
exported view with deterministic synthetic data.

## Explore the library

- **Views** introduces `Calendar` and each built-in view.
- **Scenarios** covers layout edge cases, localization, time zones, and user
  interactions.
- **Customization** demonstrates range definitions, renderer replacement,
  custom view registration, and CSS extension points.

Use the toolbar to switch locale, time zone, and viewport globally. Individual
stories lock those settings only when the scenario depends on a specific value.

## Install

```bash
npm install @chronolanejs/react react react-dom date-fns @date-fns/tz
```

```tsx
import Calendar from "@chronolanejs/react";
import "@chronolanejs/react/styles.css";

<Calendar
    view="week"
    date="2026-09-14"
    events={events}
    locale="en-US"
    timeZone="UTC"
/>
```

## Localization

`locale` selects date-fns conventions, including weekday names and 12- or
24-hour time formatting. Calendar-owned language is configured separately
through complete `formatters` and `messages` registries. English defaults are
exported for stable, explicit extension outside render:

```tsx
import {
    defaultCalendarMessages,
    type CalendarMessages
} from "@chronolanejs/react";

const messages: CalendarMessages = {
    ...defaultCalendarMessages,
    previous: () => "Previous period",
    next: () => "Next period",
    agendaEmpty: () => "No events in this period."
};

<Calendar locale="en-GB" messages={messages} />
```

The registries are intentionally complete rather than `Partial`: TypeScript
reports missing text, and the library does not perform hidden merge behavior.

## Testing model

Stories are render tests by default. Interaction stories execute browser-level
assertions, and accessibility checks run with failure-level enforcement. Pure
date, range, and layout behavior remains covered by the package's Node tests.

All examples use fixed dates and fictional data so results remain stable across
machines and visual baselines.

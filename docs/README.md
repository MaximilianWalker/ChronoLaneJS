# Documentation

Use these guides to integrate ChronoLaneJS, understand its public contracts,
and customize calendar behavior without depending on implementation details.
The same canonical Markdown is available on GitHub and on the
[documentation site](https://maximilianwalker.github.io/ChronoLaneJS/docs/).

## Start building

Follow [Getting started](./getting-started.md) to install the package, model
events, choose a view, connect state, and enable interactions. Use the
[examples](./examples.md) for complete Vite and Next.js integrations and focused
patterns for resources, localization, renderers, and event updates.

## Customize the calendar

[Styling and theming](./styling.md) covers dimensions, CSS variables, stable
class hooks, responsive behavior, and custom renderers. Review
[Accessibility](./accessibility.md) before replacing renderers or connecting
selection, opening, movement, and resize behavior.

## Look up a contract

The [API reference](./api.md) documents every exported component, prop,
callback, renderer payload, type, function, default, and thrown error.

## Upgrade and release history

Use [Upgrade to v2](./migrations/v2.md) for breaking event interaction,
message, position, renderer, and sizing changes. The
[changelog](../CHANGELOG.md) records consumer-visible changes for every
published version.
